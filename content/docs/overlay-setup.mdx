## Overlay Setup

Once you have completed the above steps, setup the tracker and overlay.

<Steps>
  <Step title="Open overlays">
    <p>From the published campaign dashboard, click <TutorialText>Overlays</TutorialText> on the top bar</p>
  </Step>
  <Step title="Create new overlay">
    <p>Create new overlay</p>
  </Step>
  <Step title="Blank Slate">
    <p>Choose <TutorialText>Blank Slate</TutorialText> to start from an empty overlay</p>
  </Step>
  <Step title="The Default">
    <p>Choose <TutorialText>The Default</TutorialText> to start with a basic overlay that already includes the <TutorialText>Alert Box</TutorialText> and <TutorialText>Event List</TutorialText> and a QR code for mobile users</p>
  </Step>
  <Step title="Customize">
    <p>Use the editor to add and remove widgets, edit colors, add sounds, move them around and more</p>
  </Step>
  <Step title="Save">
    <p>Save the changes with the button above the overlay preview</p>
  </Step>
  <Step title="Copy URL">
    <p>Copy the overlay URL</p>
  </Step>
  <Step title="Add to OBS">
    <p>Add the overlay as a <TutorialText>Browser Source</TutorialText> in OBS</p>
  </Step>
</Steps>

You can edit this overlay on this page at any time, even while broadcasting. If you want to control the placement of each part of your overlay in OBS:

<Steps>
  <Step title="Blank Slate">
    <p>Use the steps above, starting with the <TutorialText>Blank Slate</TutorialText>.</p>
  </Step>
  <Step title="Add one element">
    <p>Add **one** overlay element, such as the <TutorialText>Alert Box</TutorialText> or <TutorialText>Event List</TutorialText></p>
  </Step>
  <Step title="Edit">
    <p>Edit it to your needs</p>
  </Step>
  <Step title="Add to OBS">
    <p>Save it, copy the overlay url, and add it as a browser source to OBS</p>
  </Step>
  <Step title="Repeat">
    <p>Repeat for **each** overlay element</p>
  </Step>
  <Step title="Control individually">
    <p>Now you can control each element of the overlay individually in OBS</p>
  </Step>
</Steps>
